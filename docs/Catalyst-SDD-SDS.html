1. Purpose and scope

Catalyst is a personal earnings-and-macro trading journal. The operator follows names and releases, writes a call before the print, and scores it the session after. Incomplete notes never enter accuracy.

This combined SDD/SDS describes the runnable product: a high-fidelity iPhone simulation (iOS 26 Liquid Glass) that ships in the Grok preview, plus SwiftData stubs for a later Xcode port. There is no macOS or Xcode in the build environment, so the web sim is the visual source of truth.

Item Decision
AuthOff. No accounts, no sharing.
DatabaseOff. Zustand + localStorage (catalyst-v3, seed 7).
UsersSingle operator on one device.
PublishNot published. Demo journal works offline; live tape needs network, not keys.

2. Product loop and screens

Loop: Watch tickers / macros → see the next print on the desk → lock a call (or score one that’s in) → the tape is supporting, never a destination.

Screen Specification
NowHome tab. If a print is in, score it; else lock the next call with Up / Down / Flat on the card. Ticker rail, high tape, later this week. Gear → Settings.
NamesTab. US equity/ETF universe, All / Held / Macro, swipe Mute / Remove, CSV import, last CPI / FFR / NFP print.
TapePush from Now → See all. Color flags by likely price move. Filters: All, High, Targets, Company, Today. Refresh. Rank with Grok (user-initiated).
TickerLast / change, day range, mkt cap / P/E / 52-week, typical-session vol, spark (1D–1Y), next event, flagged headlines.
EventCall first, then consensus, Tape card (last-four EPS + analyst mix), flagged headlines.
JournalOn the desk for the next print; sheet elsewhere. Direction persists on tap, conviction 1–5, reasoning, invalidation. Completion is derived, never stored.
RecordTab. Accuracy %, conviction bands (1–2 / 3 / 4–5), Pending with Score vs Complete.
SettingsGear. Theme, notify lead, demo / live, vendor keys on-device, reset demo / empty, fire notification.

Chrome: floating glass tab bar (Now / Names / Record). Dynamic Island analog (next-event countdown), launch overlay (black hold, then whoosh into the blue bead). Sheets: journal, note, headlines, article, add, CSV, macro, search. Retrieve prior IAs at git tags pre-consumer-redesign (five tabs), three-tabs, desk (no tabs).

3. Architecture

Web (runnable)
  src/components/catalyst/*     iPhone UI (visual truth)
  src/lib/catalyst/types.ts     models
  src/lib/catalyst/store.ts     Zustand + persist
  src/lib/catalyst/impact.ts    keyword High/Med/Low + kind
  src/lib/catalyst/news-fetch.ts server collectors + Grok ranker
  src/routes/api/live.ts        rotation proxy (quotes, tape, calendar)

Native (handoff, not compiled)
  native/Catalyst/*.swift       SwiftData 1:1 with types.ts

Views never call vendors. All live traffic goes through POST /api/live with an action. A tripped source (429 / timeout) cools off ~60–90s so one dead vendor does not blank the tape. Auth is off; there is no @/lib/db import and no migrations.

Stack (web): TanStack Start, React 19, Tailwind v4, Zustand, Recharts.

Stack (native target): SwiftUI, iOS 17+, SwiftData, Swift Charts, UNUserNotificationCenter. Zero third-party packages.

5. User interface specification

Theme (Apple HIG, not navy/amber):

  • Dark: true black #000000, grouped #1C1C1E
  • Light: iOS grouped gray #F2F2F7
  • Tint: system blue #007AFF / #0A84FF — interactive chrome only, never a canvas wash
  • Semantic green / red for price; orange for estimated / incomplete only
  • Type: SF Pro / system UI. Large titles 34pt bold. Review % is SF Display, not a serif
  • Liquid Glass on chrome only (tab bar, island, sheets). Content cards stay solid
  • Radii concentric: device 54, screen 44, cards 22, sheets 44 top, pills full-round

Impact colors (reuse existing tokens, no second palette): High → --color-negative (red rail + pill). Medium → --color-warn (amber). Low → hairline / muted.

Tap targets on primary News actions are 44px. Filters are a horizontal chip row so five labels never clip on a 393pt phone.

6. News tape and impact ranking

The tape is not a tab. High-impact stories sit on the desk; the full tape is a push. It is the brokerage / Yahoo Finance pattern: everything relevant to followed names today, not only scheduled catalysts.

Story kinds (not limited to these): price-target / rating changes, company announcements, SEC filings (8-K, 10-Q, Form 4), same-day coverage, partnerships, guidance, M&A, FDA, management changes.

Flag Likely next-session move Typical trigger
High (red)> ~2%PT / upgrade, 8-K, guidance cut/raise, beat/miss, M&A, FDA, CEO/CFO exit
Med (amber)~0.5–2%Buyback, dividend, product launch, partnership, desk note
Low< ~0.5%Roundup, “stocks to buy”, opinion, color

Heuristic first — keyword classifier in impact.ts so the tape paints with no model call.

Rank with Grok — user-initiated, capped at 12 headlines, model grok-4.5, max_tokens 700. Writes impact, why, scoredBy: "grok". Never runs on page load. Spends the app owner’s xAI quota.

Collector rules: up to 8 unmuted tickers, 4 items per source, Yahoo/Google/FreeNews must mention the symbol or company, Nasdaq / Seeking Alpha / keyed vendors are trusted, titles globally deduped, 60-story cap, newest first. Fixture headlines stay when live items arrive.

Demo mode does not auto-fetch. Refresh tape always can.

8. Non-functional requirements

  • Preview binds 0.0.0.0:8080. Production target is Vercel. No runtime filesystem writes, no secrets in the client bundle.
  • Vendor keys in localStorage only. XAI_API_KEY is server-only.
  • Fetch timeout 4.5s per vendor. Watchlist news capped at 8 names / 60 stories.
  • Hydration: relative fixture times; EventRow timestamps use suppressHydrationWarning.
  • Accessibility: tablist on segmented controls, 44pt primary targets, Dynamic Type via system fonts on native.
  • No related-tickers, no accounts, no push server (local / in-app banner only).

9. Native handoff

Open the repo in Claude Design / Xcode. Read CLAUDE.md first. Visual truth is the web sim. Data truth is src/lib/catalyst/.

Gate: xcodebuild -scheme Catalyst -destination 'platform=iOS Simulator,name=iPhone 16' build. Until that passes, do not claim a Simulator launch. Headline already carries url, summary, kind, impact, why, scoredBy.

10. Design decisions

  • Web iPhone sim is the runnable product because this environment has no Xcode.
  • Graphite + system blue, not navy + amber. Glass on chrome only.
  • News is a tape with move-based flags, not sentiment.
  • Free RSS before paid keys. Ticker-relevance over raw Yahoo volume.
  • Grok rank is a button, never a page-load, never tick-by-tick.
  • No related-tickers / sector recs (explicitly rejected).
  • Zustand + localStorage stands in for SwiftData; seed-versioned.
